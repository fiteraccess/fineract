OPTION 2: SETUP GPG SIGNING (Recommended for security)
--------------------------------------------------------------------------------
This is a one-time setup that will fix all future commits:

STEP 1: Install GPG (if not already installed)
   • Download: https://gpg4win.org/download.html
   • Or: winget install GnuPG.Gpg4win

STEP 2: Generate a GPG key
   gpg --full-generate-key

   Choose:
   • RSA and RSA
   • 4096 bits
   • Your GitHub email: julius.oketayot@fiter.io

STEP 3: Get your GPG key ID
   gpg --list-secret-keys --keyid-format=long

   Output will look like:
   sec   rsa4096/YOUR_KEY_ID_HERE 2026-06-03

   Copy YOUR_KEY_ID_HERE

STEP 4: Configure Git to use GPG
   git config --global user.signingkey YOUR_KEY_ID_HERE
   git config --global commit.gpgsign true

   # Set GPG program path (Windows)
   git config --global gpg.program "C:\Program Files (x86)\GnuPG\bin\gpg.exe"

STEP 5: Add GPG key to GitHub
   gpg --armor --export YOUR_KEY_ID_HERE

   • Copy the entire output (including "BEGIN PGP PUBLIC KEY BLOCK")
   • Go to: https://github.com/settings/keys
   • Click "New GPG key"
   • Paste and save

STEP 6: Sign your existing commits
   # Option A: Sign last commit only
   git commit --amend --no-edit -S
   git push --force-with-lease

   # Option B: Sign last 7 commits (recommended for your case)
   git rebase --exec 'git commit --amend --no-edit -n -S' HEAD~7
   git push --force-with-lease

   # Option C: Create a new signed commit on top
   git commit --allow-empty -S -m "chore: sign commits"
   git push


OPTION 3: REBASE AND SIGN (Most thorough)
--------------------------------------------------------------------------------
Start an interactive rebase and sign each commit:

   git rebase -i HEAD~7

   For each commit, change "pick" to "edit", then:
   git commit --amend --no-edit -S
   git rebase --continue

   After all commits are signed:
   git push --force-with-lease
